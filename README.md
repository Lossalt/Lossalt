### 我的理念

- **引用和存储解耦**：文章里写稳定的名字，图和文件可以搬走、换机器、换域名  
- **小而专**：一个接口只解决一个问题，能被读懂、能被复用  
- **走完整流程**：改动要能进主线——测试、审查、合并，而不是本地改完就算
