### 现在关心的事

- 把博客资源做成**可搬迁**的：正文引用稳定名，文件位置可以换机器、换域名  
- 用小接口解决建站里的重复问题（随机图、配图跳转、播放列表生成）  
- 走完并复用开源协作流程：Fork → 分支 → PR → Review → Merge

### 项目 Projects

| 项目 | 说明 |
|------|------|
| [**article-image**](https://github.com/Lossalt/article-image) | 可搬迁图床命名入口：WordPress 正文只写 `?res=名字`，迁站只改 `base_url`，不丢图 |
| [**random-img**](https://github.com/Lossalt/random-img) | 随机壁纸跳转接口：`pc` / `mobile` 图池，支持 302、直出、JSON |
